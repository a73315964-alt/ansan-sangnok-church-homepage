# 안산상록교회 홈페이지

담임목사 이재용, 안산상록교회를 위해 만든 홈페이지입니다. 별도 서버나 데이터베이스 없이
정적 파일(HTML/CSS/JS)만으로 동작하며, `index.html`을 더블클릭하면 바로 볼 수 있습니다.

## 실제 정보로 바꿔야 할 것 (가장 먼저 하실 일)

`js/config.js` 파일 하나만 고치면 헤더·푸터·홈 화면·오시는 길 페이지에 자동으로 반영됩니다.

| 항목 | 위치 | 설명 |
|---|---|---|
| 주소 | `js/config.js` → `address`, `mapQuery` | 실제 주소를 넣으면 지도도 자동으로 이동합니다 |
| 전화번호 | `js/config.js` → `phone` | |
| 이메일 | `js/config.js` → `email` | |
| 설립 연도 | `js/config.js` → `founded` | |
| 예배 시간 | `js/config.js` → `worship` 배열 | 이름·시간·설명을 자유롭게 추가/수정하세요 |
| 대표 색상 | `js/config.js` → `accent` | `css/style.css` 상단 `--accent` 값도 함께 바꿔 주세요 |

## 콘텐츠 채우기

- `js/bulletins.js` — 주보. 새 주보는 배열 맨 앞에 추가하세요.
- `js/sermons.js` — 설교. 유튜브 영상이 있으면 `youtube` 에 영상 ID(주소의 `v=` 뒤 값), 설교문은 `manuscript` 에 넣으세요.
- `js/daily-reading.js` — 매일 성경읽기. 오늘 것을 배열 맨 앞에 추가하세요 (성경 본문 전체가 아니라 본문 범위 + 짧은 묵상 한 줄만 담습니다 — 성경 본문은 저작권이 있어 싣지 않습니다).
- `js/dawn-prayer.js` — 새벽기도 묵상. 형식은 위와 같습니다.
- `js/news.js` — 공지사항.
- `about.html` — 교회 연혁(`<div class="timeline">` 부분)과 비전 소개 문구를 실제 내용으로 바꿔 주세요.

## 로고

주신 로고(파랑·초록 십자가)를 벡터(SVG)로 재현해 헤더·푸터·파비콘에 적용했습니다.
`js/layout.js`의 `markIcon()` 함수를 수정하면 모양·색을 바꿀 수 있습니다.

## 이미지

`images/` 폴더에 아래 파일을 넣으면 자동으로 사용됩니다(현재는 아이콘/그라디언트로 대체되어 있어
사진이 없어도 오류 없이 동작합니다).

- 담임목사 사진, 교회 전경 사진 등 — `about.html`, `index.html`의 `.pastor-photo` 영역에 `<img>` 로 교체

## 페이지 구성

- `index.html` — 홈
- `about.html` — 교회소개 (인사말·비전·연혁)
- `worship.html` — 예배안내
- `location.html` — 오시는 길 (지도는 Google 지도 임베드, API 키 불필요)
- `bulletin.html` — 주보
- `sermon.html` — 설교 (전체 목록)
- `word.html` — 성경속으로 (교회 전경 인트로 → 이번 주 설교 영상·설교문 → 매일 성경읽기 → 새벽기도 묵상 → 지난 말씀 아카이브(`#archive`))
- `news.html` — 공지사항

메뉴 구성을 바꾸려면 `js/layout.js` 맨 위 `NAV_LINKS` 배열을 수정하세요.

## 비공개 교적 관리 (login.html / gyojeok.html)

성도 이름·전화번호 등 개인정보를 다루는 화면입니다. 공개 메뉴 어디에도 링크를 걸어두지
않았고, 주소를 알아도 로그인해야만 내용을 볼 수 있습니다 (Supabase 로그인 + RLS).

- **설정 방법**: 바탕화면의 `안산상록교회-교적-비공개자료` 폴더의 `README_주의.md` 를 따라 하세요.
- 설정 전까지는 `gyojeok.html` 이 "설정 필요" 안내만 보여주고 아무 개인정보도 노출하지 않습니다.
- **주의**: 이 홈페이지 폴더를 GitHub 등에 올릴 때, `js/config.js` 에 Supabase 값을 채워도
  괜찮습니다 (anon key는 공개돼도 되는 키). 하지만 `안산상록교회-교적-비공개자료` 폴더는
  **절대 이 홈페이지 폴더 안으로 옮기거나 GitHub에 올리지 마세요** — 실제 성도 개인정보가
  평문으로 들어 있습니다.

## 올리는 방법 (예: GitHub Pages)

1. GitHub에 새 저장소를 만들고 이 폴더의 파일을 모두 올립니다.
2. 저장소 Settings → Pages → Source 를 `main` 브랜치로 지정합니다.
3. 약 1분 뒤 `https://아이디.github.io/저장소이름` 주소로 홈페이지가 열립니다.
4. 자체 도메인이 있다면 저장소에 `CNAME` 파일을 추가하고 DNS를 연결하세요.

## 나중에 추가할 수 있는 기능

지금은 별도 로그인, 게시판, 회원 관리 기능이 없는 기본형 홈페이지입니다.
회원 가입/로그인, 사진첩, 헌금 조회, 성경 통독표 같은 기능이 필요하시면 말씀해 주세요.

  (네임서버가 Cloudflare로 넘어가 있어 가비아 DNS 화면은 더 이상 반영되지 않습니다).
- 홈페이지용 DNS 레코드(A 4개 + www CNAME)는 반드시 **"DNS 전용"(회색 구름)** 이어야 합니다.
  프록시를 켜면 GitHub 보안 인증서 발급이 실패합니다.
  단, `files` 레코드는 자료실 전용이라 프록시가 켜져 있는 것이 정상입니다.

## 사진·자료 올리기

바탕화면 **`교회자료업로드`** 폴더를 사용합니다.

```
교회자료업로드/
├── 공개-사진      ← 예배·행사 사진 (홈페이지에 쓸 것)
├── 공개-문서      ← 주보 PDF 등
├── 비공개-자료    ← 교적부·명단 등 개인정보 (외부 공개 안 됨)
└── 업로드.bat     ← 더블클릭하면 업로드 시작
```

올린 뒤 생기는 `주소목록.txt` 에 각 파일의 인터넷 주소가 정리됩니다.
홈페이지에서는 `js/config.js` 의 `filesBase` 값 뒤에 파일 경로를 붙여 쓰면 됩니다.

|---|---|---|
| `ansan-sangnok-church` | 사진·문서 | 공개 |
| `ansan-sangnok-private` | 개인정보 자료 | 비공개 |
